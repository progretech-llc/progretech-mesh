# Mixed native factory

Owner-approved 20 October 2026. One workstation gateway can advertise explicitly bound native Hermes, OpenCode, Codex, OpenClaw and OpenHarness sessions. Physical Interns remain outside the discovered workstation Hermes roster. Native histories, tools, models and permissions stay with each installation. Mesh does not create a second agent fleet.

Use Connect → Add tool on an existing owned host. Select the native tool, copy its one-time payload into that installation/session, and follow its checksum-verified helper. The helper checks the existing gateway/origin, probes the exact native identity and atomically adds its binding. A credential-checked host acknowledgement completes enrollment; server authorization alone is not success. Repeat enrollment is idempotent for the same native identity. Cancelled, expired or differently replayed payloads fail closed.

For a native Harness session, the ProgreTech CLI must support `followup --check` and `delegate-followup` (installed factory.8 or later). Run the payload inside the actual target Harness. It can grant Mesh permission to continue that session while preserving its original creator and close/spawn authority. An outside process cannot grant permission to another person's session. Mesh-created sessions already have their creator's follow-up authority. Follow-ups require an idle session and a unique receipt; unknown delivery is reported without duplicate submission.

Choose a visible entry as Scrum Master through the existing owner control. Mission Control reports each entry's actual platform; it does not relabel every agent as Hermes. Missing or ungranted sessions are disabled, rather than replaced with an inferred agent. A task that exceeds the bounded wait is reported still running; inspect its native receipt/session before another request.

Hindsight is configured in each supported native tool, not a Mesh database. Shared skills and source knowledge remain native tool resources. A successful roster heartbeat proves connection, not successful work, memory access or artifact quality.

Qualification: actual local Codex, OpenCode, OpenClaw and a Mesh-owned native Harness session returned a bounded test response. Imagen rendered an actual PNG and the reference presets rendered PNG/MP4 files. Enrollment, CSRF/ownership, credential binding, exact identity, replay refusal and native follow-up permissions have focused automated coverage. Offline machines are not stopped sessions.
