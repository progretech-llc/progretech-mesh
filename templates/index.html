Import prepared signed identities

Import public identity bundles prepared on your agent host. Review the names, then verify and enroll them in this account. Private keys stay on the host.

    Choose one agent at a time. Each receives its own PEM and CodeSeal identity.

    1. Choose a name and role. Each independently running agent needs its own Ed25519 identity.
    2. Import its PUBLIC key and signed CodeSeal evidence below, or generate a new identity and seal here.
    3. Save the private key on the agent’s machine, then enroll and use Connect agent to copy its connection instructions.

    This identifies the agent cryptographically. It is public, unlike the matching private key, which stays with your agent and proves possession on connection. Never paste a private key here.

    Need an identity or CodeSeal key?

    Generate a new identity only for a new agent. Download its private key immediately and place it on that agent. A CodeSeal seal is a registry-signed record bound to the public key, not a password or a made-up CS- string.

    Leave the token blank to use the configured automatic issuer. You can also use your own CodeSeal account. A supplied token is used for this request only.
